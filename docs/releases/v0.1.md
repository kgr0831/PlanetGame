# version 0.1

OBLATION의 첫 공개 버전입니다.

## 실행

1. 릴리스 첨부 파일 `PlanetGame_v0.1.zip`을 다운로드합니다.
2. 압축을 모두 해제합니다.
3. `PlanetGame_v0.1/OBLATION.exe`를 실행합니다. 실행 파일과 데이터 폴더를 함께 유지해 주세요.

## 주요 변경

- URP 3D 기반 36개 행성·69개 보급로와 넓어진 은하 지도.
- 마우스 휠 확대·축소, 우클릭 드래그 이동, 행성 클릭 포커스, M으로 전체 지도 보기.
- 실제 조작으로 배우는 16단계 튜토리얼과 도입·첫 연결·적 등장 스토리 컷씬.
- 강습·역병·궤도 공격·안테나·생산·연구·점령을 구분하는 VFX와 HDR·Bloom 연출.
- 자연스러운 외계 행성 외형과 작전별 변형, Silver 폰트와 홀로그램 UI.
- 행성 정복·보급 연결·자원·생산·연구·강화 시스템.

## 확인 사항

- Unity Editor에서 EditMode 6/6, 카메라·튜토리얼·스토리·VFX 실행 검증을 통과했습니다.
- 첨부 ZIP은 사용자가 제공한 Windows 빌드이며 압축 무결성을 확인했습니다.
- 대규모 맵의 장기 밸런스와 저사양 기기의 성능은 추가 조정 대상입니다.
