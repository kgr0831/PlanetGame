# 행성 외형

2026-09-27 사용자 피드백에 따라 자연스러운 외계 천체의 지질과 대기를 적용했다. 지도 확장으로 총 36개 행성이 되었으며, 아래 12개 원형을 바탕으로 중간·외곽 성역 24개에 별도 지형 시드와 변형을 저장했다. 새 작전마다 모든 행성의 지형·색조·구름량·기울기를 제한된 범위에서 다시 생성한다.

`Assets/Shaders/OblationPlanetStyles.hlsl`에서 넓은 지질 변화와 미세한 침식·퇴적층을 계산한다. 인공 격자·판넬·다각형 테두리·반복적인 긁힌 선을 제거했다. 충돌 분지는 위치와 크기가 다른 구덩이가 겹치는 방식이며, 가스층은 폭이 불규칙한 구름대다. 측면 조명과 얇은 대기로 밝은 면과 밤의 면을 구분한다.

행성 머티리얼의 `Surface Type`, `Surface Shadows`, `Surface Highlights`, `Luminous Features`, `Style Variant`로 조절한다. `OblationPlanetView`의 대기 색·강도와 구름 색은 진영 색과 분리해 저장한다. 구름 없는 행성은 해당 렌더러를 비활성화한다. 고리는 `Body/OrbitalRing`에 직렬화돼 있다.

저장된 씬은 바로 실행할 수 있다. 기본 행성 셰이더/대기 작성 후 외형을 재적용하려면 `tools/OblationPlanetVarietyBuilder.cs`의 `Build`를 실행한다. Play 모드의 `OblationPlanetReview.Gallery`는 위 순서를 가로 4개·세로 3개로 담은 `Temp/planet_variety.png`를 생성한다.

## 작전별 랜덤 변화

- 새 작전 시작 시 `OblationGame.AppearanceSeed`를 생성하고 각 행성에 독립적인 `VisualSeed`를 부여한다. 지형의 분포·크기, 색상 약 ±7도·채도 ±12%·명도 ±10%, 구름량 ±25%, 구름 임계값 ±0.025, 회전 각도와 작은 기울기를 달리한다. 구름이 없는 유형은 계속 구름 없이 표현한다.
- 같은 작전 동안 생성된 지형과 팔레트는 유지된다. 행성 회전과 구름 애니메이션은 계속 재생된다.
- 원본 머티리얼에서 매번 변형값을 계산해 색상 변화가 누적되지 않는다. 런타임 머티리얼만 수정하고 종료 시 정리한다. 외형용 `System.Random`은 게임의 전투·이벤트 난수와 분리된다.
- `OblationPlanetReview.VerifyVariation`는 같은 시드의 재현성, 다른 시드의 지형 변화, 새 작전의 시드 갱신, 원본 머티리얼과 게임 난수 상태 보존을 확인한다.
