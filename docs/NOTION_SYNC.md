## 구현 판단

- `v_0`의 행성 유형 3종은 더 최근 `v_1`의 **한 종류의 행성에 적용하는 특화**로 해석했다. 기존 3개 선택 화면은 특화 선택으로 이름을 바꿨다.
- `게임의 주요 시스템`에서 취소선 처리된 기습 설명은 재구현하지 않았다. 질병 공격은 별도 **역병** 방식으로 표시한다.
- 피드백의 YouTube 링크 `CvpWY35ZgGQ`는 **적 변형 아이콘 UI 모드 시연** 영상이다. 사용자는 행성 확대의 별도 참고 영상이 없다고 확인했다. 카메라 이동 축소와 집중 UI는 페이지의 문장 요구를 기준으로 구현했다.
- 절차적 행성 생성과 거리 규칙은 문서에 `고민중`으로 적혀 있다. 2026-09-27 사용자의 명시적인 대규모 지도 확장 요청에 따라 저장된 지도를 36개 행성·69개 보급로로 확장했다. 위치와 연결은 고정 저작 데이터이며 외형만 새 작전마다 제한적으로 변한다.
- 상점·가격·팀 구성은 기획 메모다. 튜토리얼은 2026-09-27 사용자의 추가 요청에 따라 카메라·자원 조작을 포함한 16단계로 보강했다. 실제 생산·목표 선택·강습·점령·안테나·연구와 카메라 접근·전투 추적을 사용한다. 사용자 요청으로 추가한 3개 장의 스토리 대사는 기존 소재를 이용한 구현 초안이며 확정된 노션 시나리오와 동일하다는 의미는 아니다.
- 최신 사용자 피드백에 따라 기본 HUD를 자원 보유량과 상황별 행동으로 줄였다. 수입·기록·행성 상세는 사용자가 펼치고, 운영 기능은 세 탭으로 나눈다. 튜토리얼 중에는 해당 장면에 필요한 실제 조작만 보여 준다.
- 2026-09-27 사용자의 빠른 템포 요청을 우선해 기존 첫 정복 6~8분 목표와 초기 대기를 변경했다. 현재 값과 검증 기준은 `BALANCE_TELEMETRY.md`에 기록한다.
- 전역 저장 게임 기능은 아직 없으므로 저장 파일의 ID 규칙은 현재 적용 대상이 없다. 추가할 때 에셋 대신 ID와 변경값만 기록한다.

## 확인해야 할 점

- 새 경제·연구·안테나의 장기 플레이 밸런스는 수동 플레이 측정이 필요하다.
- 조우별 고유 사건과 정찰 이미지의 구체 동작은 페이지에 충분히 정의돼 있지 않다.
- `게임의 주요 시스템`: 행성별 기술은 획득과 수치 효과까지 구현했다. 금속·생물권·에너지 환경은 생산량에, 고열·저온은 역병 도착 시간에, 중력 우물은 공격 도착 시간에 적용한다. 나머지 환경별 상성은 구체적인 규칙이 정의되지 않았다.
- `전체적인 게임 기획v_1`·`태크 트리 올리기`: 유닛별 강화 2개와 역할 전환 1개를 추가했다. 연구 진행은 행성 상태창·운영 창·상단 HUD에 표기하고, 행성 상태창에는 행성별 내부 단면 미리보기를 표시한다. 내부 장면의 구체적 아트 방향은 아직 기획에 없다.
- `자원 설정`: 최신 사용자 요청에 맞춘 빠른 템포로 전환했다. 전체 캠페인의 연구·절멸 시점과 회복 가능성은 추가 측정이 필요하다.
- `SO구조도`: 연구 선행 관계의 순환 검사를 EditMode 테스트에 추가했다. 저장 파일의 ID 형식과 모든 조우·점령 조건의 데이터 참조는 아직 구현되지 않았다.
