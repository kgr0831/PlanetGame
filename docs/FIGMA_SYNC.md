## 현재 설계에서 확인한 내용

- 제목 화면: 시작, 옵션, 나가기. 시작 시 페이드 인 후 아군 행성 하나가 보인다. 시작 행성은 유닛 생산형이다.
- 은하 지도: 연결된 행성 간 이동/전투, 아군·적군의 점유 정도를 행성 외곽선으로 표현한다.
- 행성: 유형 및 특성이 전투와 개발에 영향을 준다. 인구는 행성별 60~120억 규모이며, 0이 될 때 점유율 우세측이 소유권을 얻는다. 회복 시간은 약 10분으로 기획되어 있다.
- 행성 개발: 유닛 생산, 제조, 에너지 생산. 특화 방향은 질병·거대 괴수·세뇌, 초거대건축물·궤도무기·블랙홀, 별·유기체·무기물 등이다.
- 적 AI: 플레이어를 인지한 후 활동하고 전략에 대응하는 병기를 개발하며, 행성의 지리와 특성에 맞춰 개발 방향을 고른다.
- 참고 이미지 노드 `5:15`, `5:23`, `5:30`은 게임 스크린샷/화이트보드 사진이다. UI 에셋이 아닌 시각·기획 참고 자료로 취급한다.

## 구현 범위와 기준의 구분

- 현재 Unity 씬에는 제목/옵션/종료, 행성 지도, 연결 항로, 전투·연구·행성 역할 UI가 Inspector 객체로 배치되어 있다.
- 2026-09-27 수동 재확인에서 페이지 메타데이터는 152개 노드·길이 14,777자·해시 `3d61841f`로 기준과 같았다. 새 Figma 변경은 없었고, 사용자의 명시적 요청에 따라 기존 기획의 미반영 항목을 적용했다.
- 노드 `5:19`, `5:33`: 시작 후 행성 하나만 보이는 집중 화면과 시작 행성의 유닛 생산 유형을 적용했다. `Enter` 또는 버튼으로 은하 지도에 전환한다.
- 노드 `32:13`, `34:9`: 행성별 인구를 60~120억으로 설정하고, 인구 0에서 최대치까지 600초에 걸쳐 선형 회복하게 했다. 점령 직후 인구는 0이다.
- 노드 `5:21`, `32:13`: 플레이어·적의 점유 정도를 두 색의 행성 외곽선으로 나타내고, 인구가 0이 될 때 점유율이 높은 쪽이 소유권을 얻도록 했다. 점유율 동률이면 마지막 공격 측을 선택한다.
- 노드 `34:27`, `34:41`, `34:49`, `34:57`: 개발 방향을 유닛 생산·제조·에너지 생산으로 맞췄다. 유닛 생산 행성은 전투/노동 유닛을 자동 생산하고, 제조 행성은 채굴량 +50%와 산업력 생산, 에너지 행성은 이동·개발용 에너지 생산으로 반영했다.
- 노드 `34:45`, `34:12`, `34:15`와 세부 특화 분기는 아직 시제품에 없다. 연구 속도와 유닛 생산 행성 수의 연동, 지형/전략에 적응하는 AI, 웜홀, 질병·거대 괴수·블랙홀 등은 별도 설계와 검증이 필요하다.
