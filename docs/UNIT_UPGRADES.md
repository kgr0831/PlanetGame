# 유닛 강화 규칙

기준: Notion `전체적인 게임 기획v_1`, `태크 트리 올리기`. 유닛 8종마다 기본 강화 2개와 역할 전환 1개를 둔다. 정의는 `UnitUpgradeSO`로 저장하고 유닛 ID로 연결한다.

## 플레이 흐름

1. 유닛 특화 행성에서 유닛을 생산해 보유한다.
2. 행성 운영 창의 강화 버튼에 보유 유닛의 미완료 강화가 최대 6개 표시된다. 완료한 항목은 목록에서 빠지고 다음 항목이 나타난다.
3. 생체 55·광물 15·신경 20을 소비하면 강화가 즉시 완료된다. 각 강화는 캠페인 동안 한 번 적용된다.
4. 공격력 강화는 전투 기여도에, 이동 강화는 도착 시간에, 내구력 강화는 작전 후 병력 회수량에 반영된다. 정찰체 감각은 정찰 반경 +30%, 돌격체·공성체 관통은 대상 방어력 10% 무시로 적용된다. 세 번째 강화는 공격 방식에 맞는 역할을 추가한다.

`OblationDataBuilder.Build`는 기존 강화 에셋을 ID로 찾아 갱신한다. 새 강화를 추가할 때는 고유 ID, 유닛 ID, 배율, 역할 태그를 지정하고 `OblationSmokeTests.NotionCatalog_HasValidIdsAndReferences`로 ID·유닛별 개수·연구 참조를 확인한다.
